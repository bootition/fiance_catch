# 46 用户反馈第十九轮修复

**日期**：2026-08-28
**触发**：用户 6 条反馈——退款必须严格等额；无 90 天限制；亲情卡归副业收入；余利宝/网商银行忽略；新增生活费；退款无法处理诊断。

## 1. 退款严格等额
- 已移除“部分退款”候选逻辑：退款金额必须**严格等于**原消费金额。
- 小于或大于原消费均不生成候选。
- 时间窗口仍无限制（可跨长时间匹配）。

## 2. 亲情卡 → 副业收入
- 新增 active 规则：商品说明含「亲情卡」、支出方向 → 收入 · 副业收入。
- 存量自动处理：**16 笔**。

## 3. 余利宝/网商银行忽略
- 新增内置规则：`余利宝` / `网商银行` 中性流水 → 调拨丢弃，不影响收支。
- 存量自动处理：**9 笔**。

## 4. 收入新增“生活费”
- 新增收入分类：**生活费**。
- 新增规则：
  - 商户含「邱景衡」、收入方向 → 生活费
  - 商户含「二姑」、收入方向 → 生活费
- 存量命中：**9 笔**。

## 5. 退款无法处理诊断

当前退款待办 46 条：
- 有候选：**3 条**（金额相同、平台相同，但候选多个，需人工选）。
- 无候选：**43 条**。

无候选的原因不是 90 天窗口，而是：
1. **原消费还在“待确认”未分类**：退款待办只能匹配已经入账的消费。之前规则清扫把很多消费退回待确认，这些消费入账后候选才会出现。
2. **金额不同**：按你最新要求，退款金额必须严格等于原消费；微信部分退款（如 23 元退款对应 239.96 元原单）不再自动生成候选。
3. **原消费金额/平台确实没有对应**：例如跨平台退款。

这些退款不会丢失，等原消费重新分类入账后，系统会自动匹配并冲销。
