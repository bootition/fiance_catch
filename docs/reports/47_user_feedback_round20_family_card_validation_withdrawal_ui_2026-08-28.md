# 47 用户反馈第二十轮修复

**日期**：2026-08-28
**触发**：用户指出——亲情卡是支出却被写成收入；数据库未阻止支出方向写收入规则；提现界面没有显示哈利布朗等调拨分类。

## 1. 亲情卡已纠正
- 原因：上一轮把“亲情卡”规则写成了 `支出方向 → 收入·副业收入`，这是错误。
- 已纠正：
  - 规则改为 `支出方向 → 消费·日常缴费`（可再调整）。
  - 已把 16 条已入账的亲情卡记录从收入改为消费·日常缴费。
  - 备份：`.data/ledger.sqlite-20260828-212040.bak`

## 2. 规则方向校验
- 新增服务层校验：规则方向必须与目标类型一致。
  - `支出` → 只能消费/调拨
  - `收入` → 只能收入
  - `不计收支` → 只能调拨
- 新增回归测试：支出方向写入收入规则会被拒绝。
- 引擎与规则清扫也增加同样的方向校验，防止再次产生方向错误的账本记录。

## 3. 提现界面分类
- 提现用途选项简化为：
  - 投资/调拨
  - 现金消费
  - 其他
- 移除界面中的「未追踪账户调拨」独立选项。
- 默认分类下拉显示调拨专用分类：**攒股收息 / 哈利布朗 / 虚拟货币 / CS饰品**。
- 选择“现金消费”时才显示消费分类。
