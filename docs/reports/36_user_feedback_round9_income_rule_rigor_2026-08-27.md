# 36 用户反馈第九轮修复

**日期**：2026-08-27
**触发**：用户质疑“只要支付宝收入就归为副业收入”是否严谨。
**结论**：用户理解正确，上一版宽规则不严谨。本轮已删除宽规则，改为更严格的形态识别。

## 旧规则（已删除）

- id 61：`platform=alipay + direction=income + raw_type=收入` → 副业收入
- 问题：未来支付宝工资、报销、平台结算等收入都会被误判。

## 新规则（内置形态识别，不再是无差别匹配）

只有同时满足以下形态才自动归为副业收入：

1. `支付宝 + 收入方向 + raw_type=收入`
2. 且满足其一：
   - 交易对方被平台脱敏（含 `*`），且商品说明长度 ≥ 10（对应真实闲鱼商品标题，避免“闲鱼虚拟资料”这类测试短文本）
   - 商户为已知副业来源：`网易BUFF卖家`

不满足的公司/机构收入会进入待确认，由用户处理。
