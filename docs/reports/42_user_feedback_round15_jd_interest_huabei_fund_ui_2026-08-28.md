# 42 用户反馈第十五轮修复

**日期**：2026-08-28
**触发**：用户 6 条反馈——京东微信订单、退款界面逻辑、花呗还款、余额宝利息、债券基金买卖、高风险区 UI 紧凑化。

## 1. 京东微信订单 → 日常三餐
- 修复：`京东-订单编号3476434004379676` 这类带前缀的订单也识别；微信平台同样生效。
- 存量命中：**21 笔** 全部归入日常三餐。

## 2. 退款界面设计逻辑说明
- 退款卡片从上到下：退款信息 → 候选原消费列表 → 关联按钮。
- 之前看起来“两排”是因为同一退款存在多笔相近原消费；每行是独立账本记录。
- 现在候选以**表格**展示：选/账本ID/日期/商户/原金额/已退/可退/匹配依据/原单号，按列对齐，不再拥挤。
- 候选唯一自动冲销；多候选由用户选账本 ID；无候选等待原消费先分类。

## 3. 花呗还款
- 判断：之前消费已经记过支出，花呗还款只是还钱，不重复记支出。
- 现在内置规则：支付宝「花呗 + 还款/信用借还」→ 调拨（丢弃，不计收支）。
- 存量处理：**6 笔**。

## 4. 余额宝利息
- 结论：账本里有，之前被当成“余额宝”关键词自动归为调拨，所以没在收入里看到。
- 修复：`收益发放/利息` 的中性流水 → **收入 · 其他收入**。
- 已把历史 **447 笔**调拨改为其他收入。

## 5. 债券基金买卖
- 买入/卖出/赎回都属于资产搬家，不记消费、不记收入。
- 已写入规则：
  - 商户「蚂蚁财富」→ 调拨 · 哈利布朗
  - 商户「网商银行」→ 调拨 · 哈利布朗
  - 说明含「卖出至余额宝」→ 调拨 · 哈利布朗
  - 说明含「基金赎回」→ 调拨 · 哈利布朗
- 存量处理：新增基金调拨若干笔；买卖不会污染消费/收入统计。

## 6. 高风险区 UI 紧凑化
- 卡片改为紧凑结构：
  - 退款候选改为表格
  - 提现/人际/中性表单改为单行紧凑布局
  - 分类选择与下方分类区一致
- 页面不再显得肿大。
