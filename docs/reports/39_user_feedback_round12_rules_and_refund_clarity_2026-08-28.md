# 39 用户反馈第十二轮修复

**日期**：2026-08-28
**触发**：用户 7 条反馈——话费、分类下拉混杂、起点币、美团形态、退款候选疑似重复、基金归哈利布朗、拼多多商品信息缺失。

## 1. 话费 → 日常缴费
- 新增规则：商品说明含「话费」→ 日常缴费；商户「中国电信」「中国移动」→ 日常缴费。
- 已应用到存量待确认。

## 2. 分类下拉不再混杂
- 选择「消费」只显示消费分类，选择「收入」只显示收入分类，选择「调拨」只显示调拨专用分类。
- 实现：非当前类型的 optgroup 同时 `disabled + hidden`，切换类型即时过滤。

## 3. 起点币 → 日常娱乐
- 新增规则：商品说明含「起点币」→ 日常娱乐。存量命中 7 笔。

## 4. 美团消费形态识别
- 新增内置美团规则：
  - `美团订单-纯数字编号` → 出行交通
  - 有商品名称（含中文）→ 日常三餐
- 不适用：`合并支付购买` 或空说明。

## 5. 退款候选“两排相似菜单”
不是重复 UI。每个候选都是独立的原消费账本记录，只是商户/金额相近。为便于区分，候选行新增：
- `账本 #ID`
- 原交易单号
请按 **账本 ID / 日期 / 单号 / 已退金额** 选择，不要只看名称和金额。

## 6. 基金 → 调拨·哈利布朗
- 新增规则：商品说明含「纳斯达克」「标普500」「黄金」→ 调拨·哈利布朗。
- 并新增机制：active 调拨规则可自动处理高风险区的 `other_neutral`。
- 存量命中：纳斯达克 15、标普500 16、黄金 18。

## 7. 拼多多商品信息
- 结论：当前账单里确实没有商品信息。支付宝导出的 CSV 对拼多多交易只给：
  - 交易对方：`拼多多平台商户`
  - 商品说明：`商户单号XP...`
  - 备注：空
- 系统没有删除这些字段，账单本身就没提供；无法从现有数据还原具体商品。
- 建议：不确定的拼多多交易可留在待确认，或用金额+时间回拼多多 App 订单查找。
