# 43 用户反馈第十六轮修复

**日期**：2026-08-28
**触发**：用户要求——退款不限制时间窗口并按“当天/时间相近、同平台、同金额”优先匹配；高风险区翻页不跳底；基金处理只给建议不要擅自写规则；规则需包含纯债C等。

## 1. 退款匹配策略更新

- **取消 90 天窗口限制**：现在可以跨长时间匹配原消费。
- 优先级：
  1. 原交易订单号
  2. 商户单号
  3. 同平台 + 同金额 + 同一天
  4. 同平台 + 同金额 + 3 天内
  5. 同平台 + 同金额 + 7 天内
  6. 同平台 + 同商户 + 同金额
  7. 同平台 + 同金额
  8. 仅同金额（跨平台）
- 自动冲销条件：
  - 只有 1 个候选 → 自动冲销
  - 有多个候选但第一名领先第二名 ≥10 分且第一名 ≥80 分 → 自动冲销第一名
- 本轮额外自动冲销：**5 笔**
- 退款待办：55 → **50**
