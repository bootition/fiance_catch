# 44 用户反馈第十七轮修复

**日期**：2026-08-28
**触发**：用户 4 条反馈——退款 #690 同日同平台同金额未自动冲抵；Figma 退款有原消费但无候选；提现用途为何有“未追踪账户调拨”；高风险区提现/人际卡片右侧空间浪费。

## 1. 退款 #690 已自动冲抵
- 原因：原策略要求第一名领先第二名 ≥10 分；#2403 同日同平台同金额 90 分，第二名 85 分，差 5 分，因此没有自动。
- 修复：同平台同金额同日候选 ≥90 分且分数高于第二名时，直接自动冲销。
- 结果：#690 已自动关联 **#2403**，退款待办关闭。

## 2. Figma 退款问题
- 原因：Figma 原消费 58 元，退款 65 元，金额不同；旧逻辑“金额不同”直接排除。
- 修复：
  - 退款金额大于原消费时，若同平台且同商户/时间极近，作为“覆盖候选”。
  - 关联时只冲抵原消费剩余金额（58 元），不会产生负消费；多出的 7 元不计收入。
- 结果：Figma 退款已自动冲抵原消费。

## 3. “未追踪账户调拨”来源说明
- 这不是本轮新增，是最初 PRD `docs/decisions/01_refactor_spec.md` §2.1 定义的提现用途之一：提现到银行卡时，如果该银行卡不在账本追踪范围，就记调拨。
- 未擅自添加；如果你不想要该选项，确认后我可以把它合并到“其他”或移除。

## 4. 高风险区 UI 横向布局
- 提现/人际/中性卡片改为左信息、右表单的横向结构，右侧不再空白。
- 退款候选仍为表格，扁平紧凑。
- CSS 版本更新为 `v=20260828e`。
