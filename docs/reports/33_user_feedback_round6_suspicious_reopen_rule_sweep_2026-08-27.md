## 3. 后续规则自动筛选流程（已准备）

1. 用户在待确认中重新筛选/总结规则。
2. 用户明确告诉 AI 写入规则；AI 经 `/rules` 写入并提升为 active。
3. 执行 `apply_all_rules_to_pending()`：内置交通规则 + active 用户规则一次性筛选全部 unmatched 待确认。
4. 命中的自动入账；未命中的继续留在待确认等待下一轮总结。

已新增服务 `app/decisions/rule_sweep.py`：
- `sweep_bulk_confirm_entries()`：历史 bulk_confirm 记录重过规则，未命中退回
- `apply_active_rules_to_pending()`：active 用户规则筛选存量待确认
- `apply_all_rules_to_pending()`：内置规则 + active 用户规则全量筛选
